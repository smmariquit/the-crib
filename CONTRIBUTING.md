# Contributing to The Crib

Thanks for helping maintain this static site.

## Report issues

Open a [GitHub issue](https://github.com/smmariquit/the-crib/issues) for broken links, typos, or layout problems.

## Developers

This is a small static HTML site. Edit files directly, preview in a browser, and open a PR.

### Pull requests

1. Branch from **`main`**.
2. Keep changes focused; use clear commit messages (`fix: …`, `content: …`).
3. Open a PR to **`main`** with a short description.

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
