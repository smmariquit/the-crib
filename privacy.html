Privacy Policy

Last updated: July 4, 2026

The Crib Minecraft server landing page (crib.stimmie.dev) explains how to join the server and optionally purchase VIP perks.

What we collect

  • Minecraft username — entered when starting VIP checkout so perks can be applied to the correct account.
  • Payment details — processed by PayMongo at checkout. We do not store full card numbers.
  • Server status — public player counts from the game server API (no personal profiles).
  • Technical logs — basic server logs for security and debugging.

What we do not do

  • We do not sell your personal data.
  • We do not use your information for third-party advertising.
  • We do not require payment to play on the public survival server.

In-game data

Gameplay on the Minecraft server is subject to server rules. Chat and build data are stored as part of normal server operation for moderation and backups.
