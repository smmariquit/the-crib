Teleportation & Movement

/spawnTeleport to the main server spawn.
/backReturn to your previous location or where you last died.
/tpa <player>Send a request to teleport to another player.
/tpahere <player>Send a request asking a player to teleport to you.
/tpacceptAccept an incoming teleport request.
/tpdenyDeny an incoming teleport request.

Homes & Locations

/sethome <name>Save your current location as a home.
/home <name>Teleport to one of your saved homes.
/delhome <name>Delete a saved home location.
/homesView a list of all your saved homes.

Communication

/msg <player> <msg>Send a private message to a player.
/reply <msg>Reply to the last private message you received.
/ignore <player>Block chat messages from a specific player.
/afkMark yourself as Away From Keyboard.

Bedrock Authentication

/login <password>Log in using your Java account password.
/register <pw> <pw>Register a new Bedrock account link (if applicable).

Utility & Miscellaneous

/helpView the in-game server guide.
/sbToggle the sidebar scoreboard on or off.
/bingoplusGamble an item via the BingoPlus plugin.
/playtimeCheck how much total time you've spent on the server.
/pingCheck your current connection latency to the server.
/suicideKill your character instantly.
/verCheck the current server software and version running.
Press TabView the online player list and latency.

Features & Plugins

GeyserMC & FloodgateAllows Bedrock edition players to seamlessly crossplay on the Java server.
EssentialsXProvides the core set of commands like /home, /tpa, and /back.
CoreProtectLogs every block placed and broken so griefing can be instantly rolled back.
BingoPlusA fun gambling and minigame plugin to gamble items via /bingoplus.
View Distance TweaksDynamically adjusts server view distance based on performance to keep TPS at 20.0.
