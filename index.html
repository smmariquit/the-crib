How to Join

Java and Bedrock players share the exact same server and inventory!

Java Edition (PC/Mac):

  • Add the IP crib.stimmie.dev to your server list and join.
  • Official: Buy Minecraft for $30
  • Alternative: You can install skLauncher to play for free (cracked accounts are supported).

Bedrock Edition (Mobile/Console):

  • Change your Bedrock username to exactly match your Java Name.
  • Join the server at crib.stimmie.dev (Port: 19132).
  • Type /login <password> using your Java password in chat.
  • Android: You can buy the game for ~50 pesos on the Play Store.

Note: Login sessions are securely saved for 6 hours!

Rules

  1. Don't be an asshole.
  2. Mods/resource packs that provide an unfair advantage are not allowed, such as but not limited to X-Ray, Flight, Autohitter, etc.
  3. Mods like schematica or litematica are OK, provided that you don't use the Easy Place or similar feature.
  4. Players are kindly requested not to build massive farms with many entities like mobs, chests, or hoppers as this could degrade the experience for everyone.
