Crossplay Guide

Java and Bedrock players share the exact same server and inventory.

Bedrock Instructions

1

Match Your Name

Change your Bedrock username to exactly match your Java Name. This ensures inventories sync perfectly.

2

Join the Server

Add crib.stimmie.dev with default port 19132 to your server list and connect.

3

Authenticate

Type /login <password> in chat using your Java password to verify your identity.

Security Note: Login sessions are securely saved for 6 hours, meaning you don't have to log in every single time you disconnect!

Java Edition

Just type the IP into your multiplayer menu and join. No extra steps needed!
