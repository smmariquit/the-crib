How to Join (Crossplay Guide)

Java and Bedrock players share the exact same server and inventory!

Bedrock Players:

  • Change your Bedrock username to exactly match your Java Name.
  • Join the server at crib.stimmie.dev (Port: 19132).
  • Type /login <password> using your Java password in chat.

Note: Login sessions are securely saved for 6 hours!

Java Players:

  • Just add the IP to your server list and join normally.

Server Features & Specs

  • Hardware: Intel Premium (2 vCPU), 8GB RAM, Hosted in NY (DigitalOcean).
  • World: Massive 30,000,000 block borders for the Overworld, Nether, and End.
  • Performance: Highly optimized with dynamic View Distance Tweaks.
  • Leaderboards: Competitive Battlepass system with live rankings.
